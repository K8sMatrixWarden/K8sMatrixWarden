Why each gap is undetected, and what would catch it:

- **GAP-RB**: rbac-secret-read-broad only inspects ClusterRoles by design. *Would detect with:* extend the rule to Roles and report namespace-scoped blast radius.
- **GAP-SEC1**: the scanner does not read Secret contents (least privilege). *Would detect with:* secret scanning at commit time (gitleaks) or an admission policy.
- **GAP-SEC2**: no rule inspects Secret type or token age. *Would detect with:* list Secrets by type (metadata only) and flag service-account-token.
- **GAP-IMG1**: no image/CVE scanner runs in the offline fixture. *Would detect with:* run with --live --grype (Grype on the running image digests).
- **GAP-IMG2**: no registry allow-list or signature check. *Would detect with:* admission policy (Kyverno/Gatekeeper) + cosign verification.
- **GAP-WL2**: no static rule inspects commands; the dedicated rule was removed in the scope reduction. *Would detect with:* Falco at runtime.
- **GAP-ADM**: the admission-control rules were removed in the scope reduction. *Would detect with:* restore the admission rules (evidence is still collected).
- **GAP-OPS**: the scanner now READS these kinds but has no rule on them. *Would detect with:* rules over ResourceQuota / LimitRange / PodDisruptionBudget.
